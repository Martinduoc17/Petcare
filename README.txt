PETCARE - DSY1105

Proyecto Kotlin/Gradle basado en la evaluación parcial 1.

REQUISITOS:
- IntelliJ IDEA
- Kotlin/JVM 1.9+
- JDK 17+

EJECUCIÓN:
1. Abrir la carpeta PetCare en IntelliJ IDEA.
2. Esperar la sincronización de Gradle.
3. Ejecutar Main.kt.

NOTA:
Las esperas de corrutinas están configuradas según el enunciado:
- Entrada: 3 segundos.
- Salida: 6,5 segundos.

ARCHIVOS:
- Main.kt: ejecución y datos de prueba.
- Paciente.kt: clase base.
- Canino.kt, Felino.kt, Exotico.kt: clases derivadas.
- Box.kt: gestión de boxes.
- EstadoBox.kt: estados de los boxes.
- EstadoOperacion.kt: estados de las operaciones asíncronas.
- Ticket.kt: comprobantes.
- PetCare.kt: lógica principal del sistema.
